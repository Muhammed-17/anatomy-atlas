# 3D Anatomy Atlas — Capacitor project

Offline Android app wrapping the web atlas (Three.js). Male and female bodies, English UI.

## Layout
- `www/index.html` — the whole app (HTML + CSS + JS in one file). Edit it directly.
- `www/m/` — male model (lightweight tier, binary `.wasm` geometry + `meta.json`)
- `www/f/` — female model (HuBMAP)
- `www/details.json` — muscle / joint / organ description cards
- `www/vendor/` — three.js r128 and OrbitControls (local copies, no CDN)
- `www/fonts/` — IBM Plex Sans / Mono (local)
- `android/` — the native Android Studio project (generated by Capacitor)
- `capacitor.config.json` — app id (`com.example.anatomyatlas`) and name; change them before publishing

## Build
1. Install Node 18+ and Android Studio (with an SDK and an emulator or a phone with USB debugging).
2. In this folder: `npm install`
3. `npx cap sync android` (copies `www/` into the Android project; run it again after ANY change in `www/`)
4. `npx cap open android`, then press Run in Android Studio.

## Notes
- The app forces the lightweight male tier (`m/`). To use the full male tier on tablets, copy `d/` (about 32 MB) into `www/` and change the line `const mobile=window.Capacitor?true:...` in `www/index.html`.
- Test in a desktop browser without Android: `cd www && python3 -m http.server 8000`, then open `http://localhost:8000/?tier=mobile` (female: `http://localhost:8000/#female`).
- Female data has no muscles, joints or most of the skeleton; the stomach, thyroid, parathyroid, adrenal and pituitary glands are borrowed from the male model.
